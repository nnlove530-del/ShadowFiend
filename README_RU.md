# Shadow Fiend — Fabric / Minecraft Java 1.21.4

Проект мода с мобом Shadow Fiend, яйцом призыва, собственной текстурой, рогами, короной, шипами на плечах и небольшой анимацией рогов. Основа скелета и поведения — ванильный зомби.

## Как получить JAR без установки JDK на своём компьютере

В этой среде я не смог скачать Gradle и зависимости, поэтому не могу честно приложить проверенный готовый `.jar`. В архив добавлен GitHub Actions workflow: он собирает мод в облаке, где JDK 21 уже устанавливается автоматически.

1. Создай пустой репозиторий на GitHub.
2. Загрузи в него содержимое этой папки (не сам ZIP как один файл).
3. Открой вкладку **Actions** и разреши запуск workflow, если GitHub попросит.
4. Запусти workflow **Build Shadow Fiend mod**.
5. После завершения открой его запуск и скачай артефакт `shadowfiend-fabric-jar`.
6. Распакуй скачанный артефакт и помести файл `.jar` в `.minecraft/mods`.

Для игры нужны Minecraft Java 1.21.4, Fabric Loader и Fabric API 1.21.4. На своём компьютере JDK ставить не нужно.

## Проверка в игре

Яйцо находится в творческом инвентаре → Яйца призыва. Команда:
`/summon shadowfiend:shadow_fiend`

## Примечание
Это стилизованная модель, вдохновлённая Shadow Fiend, а не извлечённая из Dota 2. Код не был собран и запущен в Minecraft в этой среде, поэтому возможна необходимость исправить несовместимость API после первого облачного запуска.
